# sinkspec

Sink identifiers and spec tokens for idempotent workflows.

**Site:** https://theworker02.github.io/sinkspec/

## Install / run

```bash
git clone https://github.com/theworker02/sinkspec.git
cd sinkspec
node src/cli.js
node --test
```
